# Instagram Clone

## About the Project

This project is a simple Instagram-inspired mobile application developed using React Native and Expo. The main goal of the project was to learn and apply mobile app development concepts such as navigation, component-based design, state management, and user interface development.

The application recreates several core Instagram features, including a home feed, stories, reels, search page, user profile, and authentication screens. It was created as an educational project and is not intended for commercial use.

---

## Features

- User login and logout
- Home feed displaying posts
- Story section with horizontal scrolling
- Search/Explore page
- Reels page with video content
- User profile page
- Light and dark theme support
- Bottom tab navigation
- Post details screen

---

## Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/instagram-clone.git
```

### 2. Open the project folder

```bash
cd instagram-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npx expo start
```

After starting the development server, scan the QR code with Expo Go on your mobile device or run the application on an Android Emulator or iOS Simulator.
